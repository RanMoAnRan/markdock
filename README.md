# MarkDock

> 原生书签侧边栏 + 精准失效书签清理二合一浏览器扩展（支持 Chrome / Microsoft Edge，纯本地运行、零数据上传）

MarkDock 将高频使用的「**书签侧边栏**」与深度维护用的「**全屏清理工作台**」合二为一：日常通过快捷键秒搜秒开、拖拽自由整理；定期一键清理失效死链、重复书签与空文件夹，并在本地回收站安全兜底。

---

## 核心功能

### 1. 原生书签侧边栏（日常高频）
- **拼音 & 首字母秒搜**：支持空格多关键词检索标题、链接与目录路径；支持中文全拼（`kaifa`）与拼音首字母（`kf` / `kfgj`）免切输入法检索并实时高亮命中汉字。
- **目录 / 最近添加 / 常用视图**：支持在 `目录 | 最近添加 | 常用` 之间一键切换，本地统计书签访问频次与最近访问时间，高频站点触手可及。
- **重复收藏提醒**：点击「收藏当前网页」或在收藏弹窗中输入链接时，自动按规范化 URL（忽略 `utm_*`、hash 与尾斜杠）检测是否已收藏，展示所在目录并支持一键定位。
- **自由拖拽排序**：支持书签、文件夹及「置顶常用」区自由拖拽调整顺序与层级（悬停折叠文件夹自动展开），直接同步浏览器原生书签顺序。
- **丰富的快捷交互**：
  - 键盘导航：`↑ / ↓` 选择、`Enter` 当前页打开、`Ctrl/Cmd + Enter` 后台新标签页打开、`Esc` 清空。
  - 鼠标中键后台打开、自定义右键菜单（新标签/后台/新窗口/无痕打开、在目录中定位、编辑、复制链接、置顶、删除并支持提示条一键撤销；再次右键快速收起菜单）。
  - 浅色 / 深色 / 跟随系统主题切换、`11px–20px` 侧边栏字号调节，以及 AI 切换栏位置（自动贴外边 / 左侧 / 右侧）自定义。
- **内置 AI 快捷侧栏**：支持在侧边栏中一键切换常用 AI 站点（ChatGPT、Claude、Gemini、DeepSeek、Kimi 等）或自定义添加当前网页；支持按需休眠释放内存，并在不支持内嵌的站点一键跳新标签页。

### 2. 全屏书签清理工作台（深度维护）
- **精准失效链接检测**：智能区分 `404/410` 死链、DNS/网络失败、超时、`5xx` 错误、HTTP→HTTPS / 跨站重定向，以及人机验证或需登录受限页面，大幅降低误删风险。
- **重复书签去重**：支持精确 URL 匹配与规范化 URL 匹配（自动剥离 `utm_*`、`ref`、`spm`、`fbclid` 等常见追踪参数）。
- **空文件夹清理与定位**：自动识别空目录及嵌套空目录（保护收藏夹栏、其他收藏夹与 Edge 工作区），支持点击一键在侧边栏展开并高亮定位。
- **白名单与本地回收站**：支持按 URL / 域名加入扫描白名单；所有删除操作先备份到本地回收站，随时一键还原到原目录；支持导出标准 Netscape HTML 书签备份文件。

## 默认快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt + B` | 打开纯净书签搜索（隐藏 AI 切换栏，再次按下自动收起） |
| `Alt + V` | 打开并展开 AI 侧栏（再次按下自动收起） |
| `Ctrl / Cmd + K` 或 `/` | 侧边栏内快速聚焦搜索框 |

> 可在浏览器扩展快捷键设置页（`chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts`）自由修改。

## 本地开发与安装

### 环境要求
- Node.js >= 20
- npm >= 10

### 常用命令

```bash
# 安装依赖
npm install

# 本地开发预览
npm run dev

# 运行单元测试（Vitest）
npm test

# TypeScript 类型检查 + 生产构建（输出到 dist/）
npm run build

# 构建并打包发布压缩包（输出到 release/）
npm run zip
```

### 在 Chrome / Edge 中加载测试
1. 运行 `npm run build` 生成 `dist/` 目录。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启右上角「**开发人员模式**」。
3. 点击「**加载解压缩的扩展**」，选择本项目下的 `dist/` 文件夹即可使用。

## 隐私与安全

MarkDock **纯本地运行**，无任何后端服务器或第三方统计 SDK。所有书签数据、访问频次统计、白名单、设置与回收站备份均仅保存在本地 `chrome.storage.local` 中。详情请参阅 [PRIVACY.md](./PRIVACY.md)。
